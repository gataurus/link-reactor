How It Works

Two simple tools that solve real problems.

🔗

Link Management

You have a long, ugly affiliate link or a complicated URL. Link Reactor creates a short, clean version on your own domain. When someone clicks it, they're instantly redirected. Track clicks, protect with a password, or disable anytime — with or without a prefix.

https://shop.com/ref?id=123&utm=abc → yoursite.com/go/sale or yoursite.com/sale
🧱

Shortcode Blocks

Need custom HTML, JavaScript, or CSS on specific pages? Create a named block in Link Reactor, paste the shortcode anywhere — posts, pages, widgets. Edit once, updates everywhere. Use the editor button for quick insertion without leaving the post editor.

[reactor block="my-code"] → Your HTML/JS/CSS appears here

After purchase, you'll receive a license key by email. Go to WordPress admin → Link Reactor → Settings, paste the key, click Activate. Done.

Can I upgrade later?

We have only one plan — Lifetime PRO. No upgrades needed.

One license per site?

Yes, one license = one domain. Need more sites? Buy additional licenses.

How do links work?

You create a key (like "sale") and a target URL. The plugin creates yoursite.com/go/sale — anyone who visits it is redirected. Track clicks or protect with a password.

How do shortcodes work?

Create a block with a title and your code. Use [reactor block="title"] in any post or page. Edit once — changes everywhere. Or use the editor button for one-click insertion.
