## 🚀 Features

- 🔄 **Smart Redirects** — 301, 302, 307 redirects with custom URL prefixes
- 🎯 **Clean URLs** — Remove prefixes entirely for short links (`yoursite.com/sale`)
- 📈 **Click Tracking** — Detailed logs with IP, UA, referrer, and device type
- 🧱 **Shortcode Blocks** — Embed custom HTML, JS, or CSS anywhere
- 💻 **Editor Button** — Quick insertion via Classic Editor and Gutenberg
- 🌍 **10 Languages** — Auto-detection (RU, EN, DE, FR, IT, ES, PT, ZH, JA, KO)
- 🎨 **Modern UI** — Dark mode, live search, and infinite scroll

Full feature list: [link-reactor.com](https://link-reactor.com/)
